# Flint brand assets

| File | Use |
| --- | --- |
| `app-icon-1024.png` | macOS app icon master: semi-flat faceted orange-brown stone on a warm cream squircle, transparent outside the squircle |
| `Flint.icns` | macOS icon (16–1024 px); the 16 and 32 px sizes use the flat stone mark |
| `stone-mark.svg` | Flat vector of the app icon stone (six facets), for small sizes and UI |
| `stone-mark-squircle.svg` | Flat stone on the cream squircle; `site/favicon.svg` is this at 32×32 |
| `favicon-16.png`, `favicon-32.png` | Raster favicons |
| `wordmark-dark.svg`, `wordmark-light.svg`, `wordmark-mono.svg` | "Flint" wordmark for dark backgrounds, light backgrounds, and one colour (`currentColor`) |
| `lockup-horizontal-dark.*`, `lockup-horizontal-light.*` | Squircle mark beside the wordmark |

Palette: accent `#ea580c` (`#c2410c` on light backgrounds), graphite `#1c1c1e`, icon tile warm cream.
